# Codex Agent Snapshots

This repository is a simple backup of dated notes describing how I work with coding agents.

Its primary purpose is preservation.

The documents are stored here so that the working method, project-start procedures, and historical snapshots remain available if:

- local files are lost;
- a computer fails;
- conversation history becomes unavailable;
- memory of earlier decisions becomes incomplete.

The repository is not intended to define a universal development methodology or a standard for other users or coding agents.

Documents may contain different languages, formats, terminology, and levels of detail because they were created at different times during normal project work.

## Contents

Typical records include:

- descriptions of the current human-agent working method;
- responsibility boundaries;
- project-start procedures;
- validation principles;
- historical snapshots of how the workflow developed;
- implementation-redacted engineering notes.

## Authority

These files are historical records and reference material.

They are not automatically authoritative for any current project.

For active work, the current project repository, validated artifacts, explicit project decisions, and current acceptance criteria remain the source of truth.

## Privacy and implementation

This public repository should contain only material suitable for public release.

Private source code, credentials, production data, internal datasets, restricted artifacts, and sensitive implementation details belong elsewhere.

## Preservation

Where useful, individual snapshots may be dated and identified by SHA-256 so that later copies can be compared with the preserved version.

Older snapshots are not rewritten merely because the working method later changes.

They record what was documented at that point in time.

In short:

**Cloud backup for engineering memory in case human memory fails or the computer dies.**
